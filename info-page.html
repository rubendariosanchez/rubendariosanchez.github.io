// Features

Everything a modern IDE
should have.

Built for developers who live in Apps Script and want VS Code-grade tools without leaving Google.

AI Autocomplete

Inline ghost-text completions

Suggestions appear as you type — just like Cursor or Copilot. Write a comment describing what you want and the AI implements it.

  • Reads context before & after the cursor
  • Works in .gs, .html, .json, .css
  • Comment-to-code generation
AI Chat

Chat panel, any model

A side panel to chat without leaving Apps Script. Use @selection, @file or @project to send context.

OpenAI Claude Gemini DeepSeek OpenRouter Kimi Nvidia ChatLLM
Live Linter

Error lens, no save required

Errors and warnings shown inline at the offending line the moment you stop typing. A pulsing dot in the toolbar alerts you instantly.

  • Unclosed brackets, unterminated strings
  • Const reassignment, duplicate params
  • Suggests === instead of ==
  • Unreachable code detection
Search

Multi-file search

Press Alt+Shift+F to search across every file in the project at once, with results grouped by file and full keyboard navigation.

  • Results grouped by file
  • ↑ / ↓ / Enter keyboard navigation
  • Instant across the whole project
Editor

Active file indicator

A toolbar button always showing the open file's name. Click for a popover with language, line count, byte size, and a diagnostics summary.

Snippets

Code snippets catalog

Pre-built catalog for JavaScript and HTML/GAS. Create, edit, and delete your own snippets — triggered by prefix in Monaco's autocomplete.

  • clog, gss, htmlgas and more
  • Built-in snippet editor
  • Triggered by prefix in autocomplete
